# GitHub 人類可讀歷史導覽

記錄格式及規範只在 [Rule 16](../../.claude/rules/16-github-human-readable-records.md)。本頁不保存 backlog 或 migration 狀態。

閱讀 Issue 先看白話說明、完成後代表什麼、不代表什麼，再看 Formal Contract 與 parent Story。重建歷史時以附日期的 HUMAN_HISTORY_SUMMARY／HUMAN_CHECKPOINT 當導覽，回讀所引用的實際 comment、SHA、verdict。

Comment 是 append-only 事件紀錄；錯誤以新 comment 更正，不能修改舊收據假裝當時已知後續結果。初始化工作只表示規劃已 materialize，不表示產品已實作。此產品沒有 Kaledoxa 的既有 ACCEPT 歷史可繼承。
